# G2 Toy Archive coverage audit

The owner reported missing Warrior Whale, Tretorous and Serpillious in the Deckbuilder. The initial toy dataset stopped at Armored Alliance; both later-season examples had Character card records but no physical variants. Tretorous Ultra had eight AA variants, four with verified Character links; BP-only construction excluded it. The Deckbuilder now explains those different outcomes in empty team searches, including another supported profile when applicable. It never adds a toy inferred from a card or automatically changes the deck format. This guidance was introduced in release `2026-11-27-deck.3` (Deckbuilder `9add3b9`), with the existing shared stylesheet unchanged.

The Toy Archive's local coverage audit (`dddfe11`) separates actual physical identities from unlinked Character printings, which may include regional, special, alternate, unreleased or conflicting records. The 197-title `g2-coverage` capture returned 191 revisions. The subsequently reviewed release `2026-11-27-pilot.15` (`1fb0354`) adds 227 variants and 210 exact Character mappings; 64 GR/EV tables and two AA package mix tables support the additions. No old physical identities, previous card links or package memberships were lost. Two existing translucent Tretorous variants gained links, and one physical EV Gillator received two selectable package-specific Character profiles. Total: 1,206 physical variants (558 G1, 648 G2), 180 models, 551 exact profiles for 550 variants, 539 named products. See the dependency's `docs/later-g2-review-2026-11-27.md` for source-specific choices.

Deckbuilder release `2026-11-27-deck.4` (`f9b1969`) adds an explicit all-season single-faction TCG construction pilot, with exact Character pairs and the same baseline zones, counts, factions and core validation. It supports the new GR/EV physical variants without changing existing saved profiles. Legends physical entries are still pending because base tables often omit released-package evidence; Fusion, special support cards and later gameplay rules remain outside the construction pilot. A 125-title follow-up capture, now selected in the helper, covers discovered missing model/faction tables and actual Legends product mix templates. Nothing was guessed from unlinked printings.
